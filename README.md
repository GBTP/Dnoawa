# Anoawa Docs

Anoawa 的静态文档站，包含新手使用指南与完整功能参考。

## 页面

- `index.html`：快速开始、下载与安装、主要功能及分步教程
- `reference.html`：按游戏页面整理的功能参考与搜索
- `assets/screenshots/`：教程中使用的实机截图

## 本地预览

直接打开 `index.html`，或在项目目录启动静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 技术说明

项目使用原生 HTML、CSS 和 JavaScript，不需要安装依赖或执行构建。
