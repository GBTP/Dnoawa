每个功能，
具体做什么

按游戏页面查找按钮、选项和工具。每项都标出入口、用途、使用条件，以及它是否会影响成绩或排行榜。

与使用指南的区别：这里适合快速查一个具体功能；如果你想从头完成一件事，请看使用指南。

共 73 项功能

Page 01

主菜单

进入游戏后最常用的一级入口。

谱面库

主菜单 › 谱面库

管理本地谱面、浏览社区曲库、查看热榜或随机选择谱面，也是开始单人游玩的主要入口。

本地可用在线功能需登录

联机

主菜单 › 联机

加入或创建多人房间，与其他玩家同步选曲和游玩。提供竞技房与娱乐房两种模式。

需登录需联网

资源包

主菜单 › 资源包

导入、应用、编辑和导出外观资源，替换音符、轨道、判定特效、音效与颜色。

本地功能

搭档

主菜单 › 搭档

选择主菜单和结算页显示的搭档立绘与对话。仅改变展示，不影响判定或分数。

不影响成绩

设置

主菜单 › 设置

调整游戏、音频、画面、延迟、语言、缓存等全局选项。

账号与个人资料

主菜单 › 头像 / 账号

登录、注册或修改昵称、头像、Bilibili UID 和密码，并查看账号状态。

Page 02

谱面库

四个标签负责不同的谱面来源与发现方式。

本地

谱面库 › 本地

显示已经导入或下载到当前设备的谱面。无需联网即可打开与游玩。

离线可用

在线

谱面库 › 在线

浏览社区全部公开谱面。下载完成后才会出现“开始游戏”。

需登录需联网

热榜

谱面库 › 热榜

按日、周、月查看社区热门谱面，用于发现最近游玩和互动较多的内容。

需登录

随机

谱面库 › 随机

从可用谱面中随机抽取一张，适合不知道玩什么时快速选曲。

搜索

谱面库 › 搜索框

按关键词筛选谱面。在线搜索会请求社区曲库，本地搜索只检查当前设备内容。

排序

谱面库 › 排序

在线列表可按最新上传、最近更新、最多游玩、最多点赞、时长、Base BPM 或曲名排列。

导入

谱面库 › 右上角“导入”

选择 ZIP / 7Z / RAR 压缩包或谱面文件夹。选择包含多个关卡子目录的文件夹时会批量扫描。

本地功能

导入说明

谱面库 › 导入旁

查看谱面、音频、封面、背景、视频和歌曲信息文件的命名与目录要求。

Page 03

谱面详情

选中谱面后，用于准备游玩、查看社区信息或管理自己的作品。

难度选择

谱面详情 › 难度

在 Past、Present、Future、Beyond、Eternal 五档中选择谱面实际提供的难度。

流速

谱面详情 › 流速

改变音符在屏幕上的移动速度，不改变歌曲速度、判定窗口或排行榜资格。

不影响成绩

开始游戏

谱面详情 › 开始游戏

使用当前难度、流速与 Mod 配置进入游玩。在线谱面必须先下载到本地。

Mod 设置

谱面详情 › Mod 设置

包含自动游玩、蛇不锁手、接蛇轨道不倾斜、变速、FOV 系数和练习模式。

开启后不上传成绩

练习模式

Mod 设置 › 练习模式

指定歌曲的一段区间进行针对性练习，适合反复处理难点段落。

不上传成绩

排行榜

谱面详情 › 排行榜

查看当前在线谱面的 Top 100 与“我的排名”。只有符合条件的正常游玩成绩会进入榜单。

需登录

下载 / 更新谱面

在线谱面详情

把社区谱面保存到本地；在线版本更新后可重新下载最新资源。

需登录

点赞

谱面详情 / 结算页

为在线谱面点赞，影响社区互动数据与热门发现。

需登录

复制手元简介

谱面详情 › 复制手元简介

将曲名、曲师、难度和谱师整理成文本，方便粘贴到手元或试玩视频简介。

编辑谱面信息

自己的谱面 › 编辑信息

修改曲名、曲师、谱师、画师、难度标记、Base BPM、简介、标签、主题色与预览区间。

仅有权限的谱面

上传谱面

自己的谱面 › 上传

将谱面分块上传到社区，可选择是否加密，提交后进入审核流程。

需登录需内容权限

演出效果

自己的谱面 › 演出效果

打开演出编辑器，为谱面制作后处理动画或配置背景视频。

仅可编辑谱面

Page 04

游玩与结算

游玩中的辅助显示、暂停操作，以及结束后的成绩分析。

暂停菜单

游玩中 › 暂停

继续当前对局、重新开始或返回谱面详情。暂停防误触可在设置中调整。

Early / Late 提示

游玩画面 / 设置 › 游戏

显示音符按得偏早还是偏晚，用于观察个人击打趋势。

仅辅助显示

高对比度模式

设置 › 显示 / 辅助

增强部分游戏元素的颜色区分，改善色觉辨识或复杂背景下的可读性。

不影响成绩

结算成绩

歌曲结束 › 结算

显示分数、评级、Pure / Far / Lost 与连击等真实结果。试算功能不会改写这里的成绩。

本局分析

结算 › 判定分析 › 左栏

用直方图、分数曲线和试算滑块解释这一局的击打分布，并估算本谱的分数最优偏移。

仅针对本局

设备校准

结算 › 判定分析 › 右栏

跨多局统计中位偏移与波动，给出更接近设备属性的建议判定偏移。

推荐长期参考

应用建议偏移

设备校准 › 应用

将建议判定偏移写入设置。建议积累多局稳定数据后再应用。

Page 05

多人联机

从寻找房间到选曲、同步下载与多人结算。

公开房列表

联机 › 刷新

获取当前可加入的公开房间，并显示房间人数、模式等信息。

需登录

通过 ID 加入

联机 › ID 加入

输入房间号加入私密房，不需要房间出现在公开列表。

需登录

创建房间

联机 › 创建房间

设置房间名、最大人数、公开性与竞技 / 娱乐模式。

需登录

节点测速

创建房间 › 测速

测试社区专用节点延迟，帮助房主选择连接状况更好的服务器。

准备

房间大厅 › 准备

表示已经完成设置并可以开始选曲；房间流程会等待需要准备的玩家。

投票选曲

联机 › 选曲阶段

每位玩家提交一张谱面或选择“任意”，所有人投票后从候选中抽取。

谱面同步

选曲后自动进行

缺少选中谱面的玩家会自动下载，并向房间上报进度；全员完成后才开始倒计时。

竞技房

创建房间 › 竞技

按正常规则游玩，符合条件的结算成绩可以上传排行榜。

可上传成绩

娱乐房与技能

创建房间 › 娱乐

目前有两个技能：判定增强会让自己在 10 秒内无论怎么打都判定为 Pure；干扰技能会在对手画面上弹出干扰动画。

不上传成绩

Page 06

资源包

管理整套皮肤，或逐个修改四十多个资源槽位。

导入资源包

资源包 › 导入

读取他人分享的资源包文件，并添加到本地资源包列表。

应用资源包

资源包列表 › 应用

一次切换整套贴图、声音、特效与颜色配置。

贴图槽位

资源包 › 资源槽位

单独替换 Tap、ArcTap、Hold、Arc、轨道、判定线、按压阴影、高度指示与背景等图片。

音效槽位

资源包 › 音效槽位

替换打击音与接蛇音，不改变音符判定。

不影响成绩

序列帧特效

特效槽位 › 参数

为判定动画设置行数、列数、播放时长和缩放，使序列帧按正确方式播放。

颜色槽位

资源包 › 添加颜色

调整 Arc 深浅色、错色、6K 轨道色、点击特效色与 Hold 特效双色等。

重置

资源槽位 / 资源包

“重置为默认”只恢复当前槽位，“重置全部”恢复完整默认配置。

导出资源包

资源包 › 导出当前配置

将当前配置打包分享，并写入名称、作者、版本与描述。

Page 07

演出编辑器

面向谱面作者的时间轴后处理工具。

新建 / 模板

演出编辑器 › 左栏

从空效果或内置模板开始，并设置效果的起止时间。

参数

演出编辑器 › 参数

声明可动画参数；运行时会自动提供时间、分辨率、节拍与 BPM 等系统参数。

参数事件

参数 › 事件

为参数指定起止时间、起止值与缓动曲线，右侧可预览变化曲线。

Shader 代码

演出编辑器 › 顶栏

编辑 mainImage 后处理代码，并通过“编译并应用”即时检查错误和预览结果。

作用域

效果设置 › 作用域

决定效果只处理游戏画面、只处理 UI，或覆盖完整屏幕。

时间轴预览

演出编辑器 › 底部

播放、暂停、回到开头或跳到指定时间；点击时间可复制当前毫秒数。

背景视频

演出编辑器 › 背景视频

为谱面导入视频背景并单独调整视频延迟；关闭视频背景设置时会回退到背景图。

保存

演出编辑器 › 顶栏

把效果写回谱面。存在改动时显示“未保存”，退出前会再次提醒。

Page 08

设置

所有会持续保存的设备与游玩选项。

谱面偏移

设置 › 延迟

校准音乐与画面的同步关系。可打开打击音效，让音效与第三拍重音重合。

判定偏移

设置 › 延迟

补偿实际触控 / 输入延迟。Late 多时调大，Early 多时调小，建议结合多局设备校准。

暂停与失焦

设置 › 游戏

调整暂停键防误触，并控制窗口失去焦点时是否自动暂停。

重叠音效合并

设置 › 游戏 / 音频

减少大量同时触发的打击音叠加，改善密集段落的声音表现。

帧率

设置 › 显示与性能

选择跟随设备刷新率或解锁帧率。更高帧率通常会增加耗电和发热。

GPU 实例化

设置 › 显示与性能

提供自动 / 高 / 中 / 低档位；选择未通过本机实测的档位时会显示提示。

Shader 后处理

设置 › 显示与性能

控制谱面演出后处理是否显示。关闭可降低部分设备的图形负担。

视频背景

设置 › 显示与性能

控制背景视频播放；关闭时，提供了背景图的谱面会自动使用图片。

缓存管理

设置 › 缓存

查看在线封面等缓存的空间占用，并一键清理。不会删除已导入谱面。

语言

设置 › 语言

切换简体中文、繁体中文、英语、日语或韩语界面。

Page 09

账号与社区

在线身份、作品管理与社区资料。

邮箱注册

账号 › 注册

使用邮箱创建账号，初始密码会发送到邮箱。

需联网

编辑个人资料

账号 › 个人资料

修改昵称、头像和 Bilibili UID；设置 UID 后，其他玩家可以从资料页前往对应空间。

修改密码

账号 › 修改密码

更新当前账号密码。

需登录

注销账号

账号 › 注销

注销时可逐项选择保留谱面、点赞与成绩；保留的数据会转到“已注销用户”名下。

不可逆账号操作

作品管理

在线谱面 › 自己的作品

上传者可以更新或管理自己的在线谱面；管理员负责审核待审内容。

需登录
